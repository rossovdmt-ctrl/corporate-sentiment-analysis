# Оценка тональности корпоративных отчётов (Corporate Sentiment Analysis)

Данный репозиторий содержит программную реализацию лексико-статистической модели оценки тональности корпоративных отчётов российских публичных компаний и её сопоставления с динамикой финансовых показателей.

## 📌 О проекте
Код написан на языке Python и структурирован в соответствии с методологией научного исследования. Модель использует специализированный словарь `EcSentiThemeLex` для расчёта долей позитивной и негативной лексики, а также коэффициенты корреляции Пирсона и индексы конкордации для оценки связи с чистой прибылью.

## 📂 Структура проекта
```text
├── data/
│   ├── raw/           # Исходные PDF-отчёты и данные о прибыли (не хранятся в Git)
│   └── processed/     # Сгенерированные CSV с результатами
├── src/
│   ├── config.py      # Настройки путей и констант
│   ├── preprocessor.py# Извлечение и токенизация текста (Формула 1)
│   ├── dictionary.py  # Работа со словарём (Формула 2)
│   ├── analyzer.py    # Расчёт тональности (Формулы 3, 4, 5)
│   └── statistics.py  # Корреляция и конкордация (Формулы 9, 10)
├── scripts/
│   ├── 01_extract_text.py # Запуск парсинга PDF и расчёт тональности
│   └── 02_make_tables.py  # Расчёт статистик и создание таблиц
└── requirements.txt   # Зависимости проекта
